A LITTLE MORE CLARITY

Hal yang mungkin
ingin Anda tahu.

Apa perbedaan aplikasi Android dan dashboard?+

Android mendukung pengambilan data dan eksplorasi AI di lapangan. Web dashboard menjadi ruang kerja untuk mengelola proyek, pustaka foto dan video, analisis, peta, perbandingan koridor, serta laporan.

Apakah UrbanLens dapat menganalisis video?+

Ya. Selain foto, UrbanLens mendukung segmentasi video untuk membaca elemen visual lingkungan. Pustaka Video pada dashboard membantu mengelola dokumentasi rekaman survei Anda.

Apakah Predicted UVI menjamin hasil perbaikan?+

Predicted UVI menunjukkan estimasi kualitas visual untuk skenario penerapan rekomendasi AI. Foto sesudah adalah visualisasi konsep. Penilaian ahli, analisis ulang, dan validasi lapangan diperlukan untuk menilai hasil implementasi.

Bisakah hasil analisis diunduh?+

Dashboard menyediakan Laporan Eksekutif yang dapat dicetak atau disimpan sebagai PDF. Menu Ekspor Data menyediakan Export CSV untuk dataset, serta JSON untuk pengolahan data lanjutan.
